# 빈스톡스 홈페이지

바이크 헬멧, 블루투스 기기, 액션캠, 마스크와 라이딩 액세서리를 소개하는 빈스톡스의 정적 브랜드 홈페이지입니다.

## 구성

- `index.html` — 전체 페이지 콘텐츠와 구조
- `styles.css` — 반응형 레이아웃과 브랜드 스타일
- `script.js` — 모바일 메뉴, 스크롤 효과, 연도 표시
- `assets/` — 브랜드 이미지

빌드 과정 없이 `index.html`을 바로 열거나 정적 웹 서버에 업로드해 사용할 수 있습니다.

## 교체가 필요한 임시 정보

- 네이버 스마트스토어 주소
- 상품명, 가격과 상세 링크
- 고객센터, 이메일, 사업자 정보
- 브랜드 소개와 가이드 원고

현재 스마트스토어 버튼은 네이버 스마트스토어 메인으로 연결됩니다. 실제 스토어 주소가 정해지면 `index.html`의 `https://smartstore.naver.com/`을 일괄 교체하세요.
